# @doodle-ds/ui

Playful neo-brutalist React components.

```tsx
import "@doodle-ds/tokens/css/tokens.css";
import "@doodle-ds/ui/styles.css";
import { Button } from "@doodle-ds/ui";

<Button variant="sun">use doodles</Button>;
```

Requires React 19 and the Doodle DS tokens stylesheet. The package exports `styles.css` and `theme.css`.
